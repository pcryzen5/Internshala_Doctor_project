# CLAUDE.md

Project: Live Medical Transcription & Clinical Summary (FastAPI + React/TS).

Read `.cursorrules` and everything in `docs/` before coding — they are the project rules and specs.
Start with `docs/IMPLEMENTATION_PLAN.md` Step 1 and complete one step at a time.

Common commands (create these in the Makefile during Step 1):
- `make dev` — run backend + frontend
- `make test` — backend + frontend tests
- `make lint` — ruff, mypy, eslint, tsc
